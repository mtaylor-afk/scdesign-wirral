## What the owner needs to do

These are in order, and set out in full in `setup-and-deploy.md`.

1. **Step 0: Vercel checks.** Note the plan (Hobby or Pro), Fluid compute and the function region. Set
   Node to 24.x.
2. **Step 1: storage.** Create a private Blob store `wvroofing` in London and the free Neon database
   `wvroofing` in London, and connect both.
3. **Step 2: core variables.**
   - `WVR_SESSION_SECRET` and `CRON_SECRET`;
   - `WVR_OPERATOR_PASSWORD_HASH`, made with `operator-hash.mjs`;
   - `WVR_LEAD_TO`;
   - `WVR_DAILY_BUDGET_USD`.
4. **Step 3: push the held commits** with the Desktop **PUSH WV ROOFING.cmd**, then run the live checks.
5. **Step 4: switch on one capability at a time.** Each key goes into Vercel, then its switch. For address
   search, also set Ideal Postcodes' own daily limit (see `cost-model.md`).
6. **Step 5: A8.** Tell Claude which keys are in and OK the spend:
   - the render benchmark (at most 16 renders, about $3);
   - pre-rendering the sample houses (at most 24 renders, about $2–3);
   - **one real enquiry email**, flagged before it's sent.

## Flags

- **Hobby is non-commercial.** That covers SC Design's own functions on the same Vercel project too.
  Move to Pro, or give WV Roofing its own Pro project, before any commercial use.
- **Vercel deprecates Node 20 on 1 October 2026.** Set 24.x (step 0); it affects the SC functions too.
- **The London region pin (`lhr1`) is still deferred.** It waits for the Hobby or Pro answer. Until then
  the functions run in Washington DC, while storage is in London (see the privacy record).
- **SC's `sharp` 0.34.5 has HIGH advisories, fixed in 0.35.x.** WV Roofing allows only JPEG and PNG
  meanwhile. Upgrade it in SC.
- **The home page's "£0 survey" statistic** now reads "Free … (concept wording, to be confirmed)". The owner
  should confirm the offer.
- **Two numbers are uncalibrated until A8:**
  - `WVR_MAX_SEAM` (50);
  - gpt-image-2.5's per-token prices, assumed equal to gpt-image-2's.
- **The default address-lookup cap allows up to £13.50 a day.** Set a lower daily limit in Ideal Postcodes'
  dashboard.
- **Contact details can't be edited on the operator screen** (a rectification gap). The workaround is in
  `operator-guide.md`.
- **SC Design's `CLAUDE.md` still contains an outdated admin credential**, in a public repository (flagged
  before).
