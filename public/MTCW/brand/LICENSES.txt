MT CREATIVE WORKS - THIRD-PARTY LICENCES FOR THE LOGO ARTWORK
==============================================================

What this covers
----------------
The M and the T in the MT Creative Works logo are original geometric shapes drawn
for this project (scripts/brand/logo-geometry.mjs). No typeface is used for them.

The words "Creative Works" in the logo were converted to vector outlines from:

  Typeface : Manrope SemiBold (weight 600)
  Copyright: Copyright 2019 The Manrope Project Authors (https://github.com/sharanda/manrope)
  Licence  : SIL Open Font License, Version 1.1 (full text below)
  Obtained : npm package @fontsource/manrope 5.3.0 (Fontsource), file files/manrope-latin-600-normal.woff

The font file itself is NOT included in this project, in the build output or on the
website. Only the outlined shapes of the glyphs for the two words appear in the logo
files, as artwork. The font is not served to visitors and no web-font request is made.

The SIL OFL permits the Font Software to be used to create artwork and documents, and
the licence is reproduced here to keep the provenance and the licence terms with the
assets. This note is a record of provenance, not legal advice.

Fonts used elsewhere on the website: none. The site uses the visitor's system font
stack and ships no font files.
